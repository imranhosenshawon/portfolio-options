# MD Rakib Hasan Portfolio

A responsive, interactive personal portfolio website built from the information in the provided academic and professional CVs.

## Included
- Responsive single-page portfolio
- Animated hero section and scrolling expertise strip
- Light/dark theme toggle with local persistence
- Mobile navigation
- Scroll reveal animations
- Research, experience, education, skills and leadership sections
- Publication DOI link
- Email and LinkedIn contact actions
- Download buttons for both supplied CV PDFs
- Supplied portrait photo integrated into the hero section

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
